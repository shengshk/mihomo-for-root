帮助程序使用说明

Mihomo For Root 使用帮助

  • 🌐 透明代理通过 Root 接管流量，无需开启 Android VPN。
  • 🎛️ 概览与启停运行模式点击即生效。模块执行按钮切换启停；指定 Wi-Fi 下切换暂停／停止，暂停时离开后恢复。
  • 📄 配置订阅支持导入 YAML、添加订阅、手动或定时刷新。纯节点或部分配置会补齐分组、规则及 DNS；生成的分组需在 Zashboard 选择节点。检查通过后才能切换。
  • ⚙️ Mihomo 覆写跟随 YAML 时保留已有值；缺失项由兜底 YAML 补齐，内置默认开启 TUN、Fake-IP、IPv6，标题会提示。手动覆写优先；关闭 TUN 后使用 TProxy，原 YAML 不变。
  • ➕ 追加系统 DNS保留原 DNS，随 Wi-Fi／移动网络变化更新追加地址。
  • 📱 应用黑白名单全部代理表示所有应用进入 Mihomo；白名单仅接管选中应用，黑名单绕过选中应用。最终连接方式由运行模式和规则决定。未安装包名会保留，安装后自动生效。
  • 🛡️ AdGuard Home独立提供 DNS 过滤。Mihomo 运行时使用其 DNS，停止时使用系统 DNS。统一接管 IPv4／IPv6 的 TCP、UDP 53 请求；无 IPv6 重定向时使用透明转发，独立于 TUN 和 IPv6 覆写。阻止 IPv6 解析仅影响 AAAA 查询；广告黑名单最多启用 3 个链接，域名及链接支持整行 # 注释。
  • 📶 代理自动启停连接指定 Wi-Fi 时暂停，离开后恢复；手动停止后保持停止。
  • 💾 独立保存橘黄色“未保存”表示有修改，展开后点击“保存并应用”，只保存当前卡片。改回已保存的值后，提醒和保存按钮消失。
  • 📝 未保存的修改折叠卡片、切换 Tab 保留草稿；刷新或重新打开页面丢弃草稿。
  • 📋 查看日志展开后自动刷新，折叠、切换 Tab 或进入后台时停止刷新。
