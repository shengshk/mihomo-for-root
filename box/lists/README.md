# 应用清单来源

## 白名单推荐清单

`proxy-apps.json` 来自 [2dust/v2rayNG](https://github.com/2dust/v2rayNG) 的 `V2rayNG/app/src/main/assets/proxy_package_name`，明确包名去重，忽略单独的 `android`。
源版本在 JSON 的 revision 中记录，GPL-3.0 许可证见 `v2rayNG.LICENSE`。这是推荐代理应用清单；不从它取反生成大陆应用清单。
黑名单继续使用 mnixry/direct-android-ruleset；两种清单独立缓存、仅在用户主动导入时追加。
